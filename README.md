# Hofknecht Homebrew tap

```sh
brew install --cask hofknecht/tap/systemtraymenu
```

[SystemTrayMenu](https://hofknecht.eu/systemtraymenu/en.html) shows your folders as searchable menus in the menu bar.
14-day free trial, then a license from https://hofknecht.eu/shop/en.html?produkt=stm.

The app is not notarized by Apple yet: on first start macOS blocks it. Open System Settings,
Privacy & Security, and click "Open Anyway".
